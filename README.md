# Full-Stack Web Application with Python Backend

A full-stack web application where I developed the **backend using Python, FastAPI, SQLAlchemy, and PostgreSQL**, and integrated it with an existing frontend.

## 👨‍💻 My Contribution

I developed the backend of this project from scratch.

### Backend

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- REST APIs
- CRUD operations
- Database integration
- Frontend-backend integration

The backend handles communication between the frontend and the PostgreSQL database through REST APIs.

## 🎨 Frontend

The frontend used in this project was **taken from an existing GitHub project** and integrated with my backend.

I did not develop the original frontend.

Original frontend source:

**[https://github.com/navinreddy20/fastapi-demo.git]**

All credit for the original frontend goes to its respective author.

## 🗄️ Database

The application uses **PostgreSQL** as the relational database.

SQLAlchemy is used as the ORM to communicate with the database.
